# Grupp 3 GoRide

Ett webbprojekt där man bokar bilar efter datum

## Funktioner
- Välj start och slut-datum 
- Få upp lediga bilar
- Välj bil
- Boka med mail

## Teknologier

- React
- TypeScript
- CSS
- API

## Kom igång 

1. git clone https://github.com/MattiasWaern/Grupp-3-TypeScript-Examinerande-gruppuppgift.git
2. npm install
3. npm run dev 
4. npm run server för att starta json-servern
